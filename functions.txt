- pthread_create    -> crea hilos (uno por filósofo. Cada hilo lanza la rutina de dormir, comer y pensar).
- pthread_detach   -> marca un hilo para que libere sus recursos automáticamente cuando termine. Puedo usarlo para autoliberarse en vez de usar join.
- pthread_join     -> Espera a que un hilo concreto termine. Me puede servir para esperar a que los hilos terminen antes de salir del programa.
- pthread_mutex_init  -> inicializa un mutex. Para inicializar los mutex de los tenedores o para proteger el acceso a variables compartidas (como imprimir o verificar el tiempo de la última comida).
- pthread_mutex_destroy -> destruye un mutex. Para limpiar recursos al final del programa.
- pthread_mutex_lock  -> bloquea un mutex. Evita que dos hilos usen una variable al mismo tiempo. Me puede servir para que dos filos no usen 1 tenedor a la vez.
- pthread_mutex_unlock -> desbloquea el mutex. Soltar el tenedor.
- gettimeofday -> Obtiene la hora actual en microsegundos. gettimeofday(&now, NULL); tv.sec -> segundos tv.usec -> microsegunds. Necesito milisegundos.
